
# Week 2 – Python for Data Engineers

## Objective
To build a reusable Python data ingestion pipeline.

## Technologies
- Python
- Pandas
- PyArrow
- Requests
- Databricks

## Tasks Completed
1. Python basics
2. CSV and JSON file handling
3. Pandas operations
4. Data cleaning
5. Joins and GroupBy
6. API handling
7. Error handling and logging
8. CSV to Parquet ingestion

## How to Run

Install dependencies:

pip install pandas pyarrow requests

Run:

python ingest.py

## Output
Cleaned Parquet files are generated inside data/cleaned.
